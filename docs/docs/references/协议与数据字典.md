# 03 · 协议与数据字典

> 所有示例取自 2026-10-25 真机响应（数值可能变化，**结构不会变**）。
> 约定：HTTP 一律 `Content-Type: application/json`；失败返回非 2xx + `{error:"…"}`。

## 1. 契约速查

### 1.1 健康与机器

```jsonc
GET /api/health   → {"ok":true,"time":"2026-10-25 13:07:17"}
GET /api/machine  → {"ok":true,"id":"647af339-…-…","name":"PC-20260302NSZS","at":"2026-10-24 14:46:15"}
```

### 1.2 上架记录（`/api/listing/*`）

```jsonc

→ 200 { "ok":true, "added":1,"updated":0,"invalid":0,"ids":["B0CXLY71HT@uk"],
        "blocked":false,"blockedCount":0,"forced":0,"todo":12,"shop":"王依凡" }
→ 200 { "ok":false,"blocked":true,
        "blockedItems":[ { "asin":"…","site":"uk","scope":"cross-shop",
                           "reason":"claims-same_asin_same_site",
                           "message":"该品已在「全天跟卖」UK 站 于 2026-10-24 23:04 上过 —— 跨店重复, 已拦截",
                           "where":[{"storeName":"全天跟卖","storeId":"2411190735976","at":"…","shop":"王依凡"}] } ],
        "message":"…","reason":"claims-same_asin_same_site" }
```

```jsonc
GET  /api/listing/fill-tasks?status=todo&limit=5   → { ok, total, items:[{ id, asin, site, fill, … }] }
POST /api/listing/fill-result
{ "id":"B0CXLY71HT@uk", "submitted":true, "ok":true, "dryRun":false,
  "readBack":{ "selling":"2411190735976=全天跟卖","site":"69131=实时站点表 GB", … },
  "fields":[{ "ok":true,"label":"价格" }], "note":"…" }

```

### 1.3 跨店台账（`/api/claims/*`）

```jsonc
POST /api/claims/check
{ "asins":["B0CXLY71HT"], "site":"uk", "storeId":"2411190735976", "scope":"family" }
→ { "ok":true,"verdict":"block",           // block | warn | pass
    "items":[ { "asin":"B0CXLY71HT","level":"block",
                "reason":"same_asin_same_site_same_store",   // 或 same_asin_same_site
                "note":"本店已上过",
                "hit":{ "src":"local","srcName":"PC-20260302NSZS",
                        "asin":"…","site":"uk","siteId":"69131",
                        "storeId":"2411190735976","storeName":"全天跟卖","shop":"王依凡",
                        "machineName":null,"at":"2026-10-24 23:04:54","status":"listed",
                        "title":"…","brand":"…","image":null } } ],
    "warns":[ { "level":"warn","reason":"cross_site","summary":"该品已在「全天跟卖」DE 站上过" },
              { "level":"warn","reason":"family_other_variant","summary":"同族另有 3 个变体在 2 个店铺上过" } ],
    "at":"…","machine":{…},"checked":1,"indexSize":2394 }
```

| 路由 | 说明 |
|---|---|
| `POST /api/claims/commit` | `{items:[{asin,site,storeId,storeName,status,title,…}]}` 写/更新台账 |
| `POST /api/claims/override` | `{asin,site,storeId,reason}` 追加强制上架审计（30 分钟内同名同站点视为已确认） |
| `POST /api/claims/rebuild` | 从上架记录全量重建（幂等，保留 override 与 ifast-sync 来源） |
| `GET  /api/claims/ledger?q=&site=&storeId=&level=&limit=` | 台账查询；返回 `total/items/sources[]/stores[]/sites[]/settings/machine` |
| `GET  /api/claims/settings` · `POST` | `{enabled:true,retainDays:180,whitelistPairs:[],blockSameStore:true}` |
| `POST /api/claims/mark-batch` | `{asins:[…]}` → `{marks:{ASIN:{n,sites[],stores[],srcs[],items[]}}}`（商品管理打标签用） |
| `POST /api/claims/platform` | `{asin, action:'rows'|'groups'}` → 实时问 ifast（需 ifast 已登录；失败 503 `{ifast:true}`） |

### 1.5 共享端口（`/api/ports*`）

```jsonc
GET  /api/ports → { "ok":true,"max":8,"min":1024,"base":3088,"ips":["192.168.86.13"],
                    "ports":[ { "port":3091,"running":true,"enabled":true,"at":"…",
                                "token":"155ca4b1",
                                "url":"http://192.168.86.13:3091/zy/155ca4b1" } ] }

POST /api/ports { "port": 3091 }        // port 可省略 → 自动分配(3090~3199)
→ { "ok":true,"port":3091,"autoChosen":true,"closedOld":[3090],
    "url":"http://192.168.86.13:3091/zy/155ca4b1","token":"155ca4b1","ips":[…],"ports":[…] }

POST /api/ports/stop|start|delete { "port":3091 }
```

行为：**默认建新的自动关旧的**（`keepOld:true` 可保留）；`delete` 彻底关闭且不再恢复；端口清单落 `ports.json`，ERP 重启自动恢复 `enabled:true` 的端口。

### 1.6 设备连接 / 双向同步（`/api/peers*`、`/api/sync/*`）

```jsonc
POST /api/peers { "url":"http://192.168.86.13:3091/zy/155ca4b1", "name":"设备B" }
→ { "ok":true,"peer":{"id":"<对方 machineId>","name":"设备B","url":"…"},
    "sync":{ "ok":true,"ms":113,"pulled":{"claims":3,"items":3,"machine":{…}},
             "imported":{…},"pushed":{"claims":2384,"items":2220},"pushError":null },
    "synced":[ {"id":"…","name":"设备B","ok":true,…}, … ] }      // ★ 连接会同步"所有已连接设备"

GET  /api/peers          → { ok,machine,total,claimsLocal,itemsLocal,claimsMerged,itemsMerged,
                             peers:[{id,name,url,online,lastSyncAt,claims,items,error}] }
POST /api/peers/sync     { "id":"…" }
POST /api/peers/sync-all {}  → { ok,total,okCount,results[],claims,items }
POST /api/peers/delete   { "id":"…" }   // 同时清空该设备的缓存数据
GET  /api/sync/export    → { ok,at,machine:{id,name},claims[],items[] }   // 只导本机
POST /api/sync/import    ← 对方推来的同结构（存进 peer-data.json[peerId]，不污染本地）
```

## 2. 数据文件字典

### 2.1 `listing-records.json`（上架记录，一条 = 一个 `asin@site`）

```jsonc
{
  "id":"B0CXLY71HT@uk", "asin":"B0CXLY71HT", "site":"uk", "shop":"王依凡",
  "status":"listed",                       // pending | listed | failed | blocked
  "savedAt":"…","listedAt":"…","refillAt":null,
  "title":"…","brand":"…","parentAsin":null,"mainImage":"…","url":"…",
  "fill":{ "initPrice":19,"bearPrice":13.2,"stock":100,"leadDays":5,
           "followMode":"now","followAt":null,"variantItems":[…] },   // 给 bridge 填表用
  "fillResult":{ "at":"…","ok":true,"submitted":true,
                 "readBack":{"selling":"2411190735976=全天跟卖","site":"69131=…"},"note":"…" },
  "uploads":[ { "at":"…","attempt":1,"ok":true,"submitted":true,
                "preflight":true?, "reason":"…","fieldsBad":0 } ],      // 新→旧，最多 30
  "blocked":false, "blockedBy":{…}, "blocks":[…], "blockCount":0,
  "failCount":0, "failReason":null, "failFields":[]
}
```

> 被拦截的尝试会另存一条 `id = "ASIN@site#blocked:<shop>"` 的记录（`status:"blocked"`），**不参与填表**。

### 2.2 `listing-claims.json`（跨店台账，一条 = `asin@site@storeId`）

```jsonc
{ "key":"B0CXLY71HT@uk@2411190735976", "asin":"B0CXLY71HT","parentAsin":null,
  "site":"uk","siteId":"69131","storeId":"2411190735976","storeName":"全天跟卖",
  "shop":"王依凡",                        // ifast 登录账号(展示用)
  "machineId":"647af339-…","machineName":"PC-20260302NSZS",
  "at":"2026-10-24 23:04:54","status":"listed",       // listed | pending | failed | deleted
  "source":"ifast-sync",                             // import | ifast-sync | ext | bridge
  "title":"…","brand":"…","image":null,
  "overrides":[ {"at":"…","machineName":"…","operator":"王依凡","reason":"强制上架","from":"全天跟卖"} ] }
```

判决口径（`claimCheck`）：同站点同 ASIN → **block**（含本店，标注「本店已上过」）；跨站点 → **warn**；同 `parentAsin` 其它变体 → **warn**；保留期默认 180 天（`claim-settings.json`）。

> 远端设备的凭证不进这个文件，只进 `peer-data.json`；查询时用 `allClaimsWithSrc()` 合并，并带 `src`（`local` 或 peerId）与 `srcName`。

### 2.3 `ifast-items.json`（ifast 店铺商品明细）

```jsonc
{ "key":"B0CXLY71HT@69131@2411190735976", "asin":"B0CXLY71HT","sku":"…",
  "siteId":"69131","site":"uk","country":"GB",
  "storeId":"2411190735976","storeName":"全天跟卖",
  "title":"…","brand":"…","image":"…","url":"http://www.amazon.co.uk/dp/…","cate":"…",
  "price":19,"initPrice":19,"lowerPrice":13.2,"stock":100,"fulfillmentLatency":5,
  "onOff":0,"itemStatus":20,"statusText":"待获取",
  "status":"listed",                     // 在 ifast 列表里存在 = 该店铺该站点有这条
  "createUserName":"王依凡","createTime":"…","updateTime":"…","ifastId":53999388,"syncedAt":"…" }
```

**字段语义（容易搞错）**
- `itemStatus` 是 ifast 的状态枚举：`0 正常 / 20 待获取 / 30 ASIN异常 / 40 异常`；**`onOff` 恒为 0，不要用它判断在售**
- 判据只有一条：**这条在 ifast 的 `item_list.json` 里存在 = 该店铺在该站点有它**（同步来的全部记 `listed`）
- 商品主键是 `asin@siteId@storeId`（含 siteId，因为没有 69136/69183 这类站点表差异会被合并）

### 2.4 `peers.json` / `peer-data.json` / `ports.json` / `machine.json`

```jsonc
peers.json      [ { "id":"<machineId>","name":"设备B","url":"http://IP:端口/zy/口令",
                     "at":"…","lastSyncAt":"…" } ]
peer-data.json  { "<peerId>": { "claims":[…同上但含 src],"items":[…],"at":"…","name":"设备B","machine":{…} } }
ports.json      [ { "port":3091,"enabled":true,"at":"…","token":"155ca4b1","note":null } ]
machine.json    { "id":"<uuid>","name":"PC-20260302NSZS","at":"…" }
claim-settings.json { "enabled":true,"retainDays":180,"whitelistPairs":[],"blockSameStore":true }
```

## 4. 时间与数值约定

- **`now()` 写的是 UTC**（`new Date().toISOString().slice(0,19).replace('T',' ')`）。解析必须按 UTC：`Date.parse(s.replace(' ','T') + 'Z')` —— 按本地解析会差 8 小时（真踩过，"30 分钟豁免"永远不成立）。
- 价格/重量：数字或 `null`（不要用 `''`／`'-'` 参与计算）。
- ASIN 一律 `toUpperCase().trim()`；站点码一律小写。
