# Amazon 商品页「搞薯条面板」功能说明

> 面向 AI Agent：面板长什么样、每个分区/字段是什么、按钮调哪个接口、算价怎么算、数据从哪来、两个新行为怎么实现。
> 源码：`$PKG\02-browser-extension\zy-panel.js`（1783 行），行号均为实测；核对时间 2026-11-22。
> 配套：`docs/references/extension-source-map.md`（全扩展源码地图、消息/存储键、接口全表）。

## 0. 一句话

打开 Amazon 商品详情页 → 右上角出现 🍟 圆球 → 点开是「搞薯条面板」：**商品信息 → 变体算价表 → 上架店铺（BG/已上架）→ 店铺管理 → ifast 直连**，数据全部来自我们自己 ERP（`/api/zy/*`，经 background 转发），面板里算好「初始价 / 承受价」后一键 `POST /api/ifast/add` 上架。

| 列 | 含义 | 交互/取值 |
|---|---|---|
| 勾选 | 是否参与本次上架 | `data-var` → `S.varsSel`（1550-1552） |
| 变体 / ASIN | ASIN + 属性 chips + 「↗」打开该变体页 | **当前页 ASIN 蓝色**（1295，见 §12）；chips 来自 `dims`/`attrs`（647-665） |

| 采购¥ | 行级采购成本；空=商品级 | 「↓填充」1630 |

| 税率% | 行级 K 值；**锁定后只读** | `SET.taxLock` 时 readonly（1309）；空=该国家默认（`effTaxPct`） |
| 汇率 | 行级汇率；空=`S.fx`（实时汇率） | 1573-1583 |
| 承受价 | **最终本币承受价**（可手改，手改后不再被公式覆盖） | 输入写 `manualPrice` + `manualBearByAsin`（1676-1691）；空=还原公式 |
| ± | 本币调整（按站点记忆，DE 默认 -3） | 空=商品级 `S.adj`；「↓填充」1632-1634 |
| 差额 | `现价 − 公式基准价`（绿/红） | 1313-1317 |
| 原价 | **公式基准承受价** `c.base`（有调整时加红色删除线） | 1318 |
| 现价 | **最终承受价** `c.now`（绿字） | 1319 |

## 9. 算价口径（改价前必读）

### 9.1 公式

```
公式基准价 base（本币） = round( round(运费 + 采购成本) × (1 + 利润率) ÷ K ÷ 汇率 )
最终承受价 now（本币）  = base + ±          （没有手填承受价时）
                        = 手填承受价         （有手填值时，公式被覆盖）
```

- 代码：`bearBase()` 284-291（基准/一键填充用）、`rowCalc()` 1226-1241（表格显示）、`uploadBearPrice()` 1736-1749（上架取值）——**三处公式必须同步**。
- 参考文案：设置视图 716「承受价格 = (采购成本 + 物流成本) × (1 + 利润率) ÷ 到手比例K ÷ 汇率（德国默认 -3）」。

### 9.2 参数优先级（行级覆盖商品级）

| 参数 | 行级 | 商品级/默认 | 兜底 |
|---|---|---|---|
| 运费 | `v.freight` | `S.freight`（重量→`/api/zy/freight/quote`，固定渠道「云途普货」477） | 0 |
| 采购成本 | `v.cost` | `S.cost`（默认 30，S 初始化 205） | 0 |
| 利润率 | `v.margin` | `S.margin`（默认 0.3） | 0 |
| 税率 K | `v.tax` | `SET.taxBySite[站点]`（`taxPctOf` 266-271）；`SET.taxLock=true` 时强制国家值（`effTaxPct` 272-276） | 0 → `kOf(0)=1` |
| 汇率 | `v.fx` | `S.fx`：`FX_DEF` 常量（30）或 `/api/rates` 实时（`useLiveFx!==false`，352-366） | 7.8 |
| ± 本币调整 | `v.adj` | `S.adj` = `SET.adjBySite[站点]`，DE 默认 -3（`adjOf` 133-136） | 0 |

### 9.3 三个容易搞错的语义

1. **「税率%」实际是「到手比例 K」**：默认 UK/DE/ES/IT/FR = `0.68`、AU = `0.85`（100、122）。`kOf()` 里 `>1` 的值按旧百分比换算 `1 - x/100`（278-283），所以兼容「填 20」的旧数据。UI 文案没改（729 提示已说明 0.68=到手比例）。
2. **汇率方向**：`FX_DEF` 是「1 本币 = ? CNY」（US 7.1、DE 7.38、UK 8.83…），公式里除以它 → 结果单位是**本币**。
3. **手填承受价优先级最高**：`v.manualPrice`（本次改）或 `SET.manualBearByAsin[asin]`（持久化）任一存在就直接用，不再走公式（295-298、1236-1239、1736-1740）；清空输入框会删除持久化值（1676-1691）。

### 9.4 上架取值必须与显示一致

`upload()` 内部：`uploadInitPrice = v.price + 初始±`（1732-1735）、`uploadBearPrice = 手填值 ?? 公式(base+±)`（1736-1749）。改公式/改列时必须三处同步，否则「面板显示一个价、上架另一个价」。

## 11. 两个新行为（已核对实现）

### 11.1 当前打开的变体 ASIN 显示蓝色

- 实现：行渲染时 `String(v.asin) === String(S.asin)` → 颜色 `#4c9aff`，并加 `title="当前打开的变体页面"`（1295）。
- `S.asin` 来源：URL 解析 `asinOf()`（43-46），`loadAll` 每次刷新都重取（342）。
- 单页应用内换 ASIN（点亚马逊自己的变体）靠 1.5s URL 轮询重载（1779-1782）；不是 MutationObserver。
- 只有**当前 ASIN 确实出现在变体列表**里才会变蓝；列表里没有当前页 ASIN 时没有任何行是蓝色。

### 11.2 初始价按 ASIN 锁定（`initPriceByAsin`）

**要解决的问题**：初始价来自数据源（`/api/zy/variants`），用户手改后切网页/重载变体会被数据源价覆盖回去。

**机制**（锁的是「用户看到的显示值」）：

| 环节 | 行号 | 行为 |
|---|---|---|
| 存储字段 | 103-106 | `SET.initPriceByAsin = { '<ASIN>': 显示价 }`，随 `zyp_v3_settings` 落盘（132） |
| 写入：手改初始价 | 1555-1571 | 非空 → `initPriceByAsin[asin] = round(输入值)`；**清空 → delete（解锁）** |
| 写入：改初始± | 1587-1616 | 显示价变了就同步锁到新显示值（input 事件即更新内存，change 时落盘） |
| 写入：一键填充 | 1495-1512 | 填充完成后把所有有价变体的显示值一起锁定 |
| 读取/回填 | 434-445 | 加载变体后 `v.price = 锁定值 − 初始±`，并 `v.priceLocked=true`。即「内部存扣掉 ± 的价、显示时再加回来」 |
| 渲染 | 1291-1303 | 显示 `v.price + ipAdj`；已锁定时输入框边框 `#3c6ea5` + tooltip「已锁定：切换网页/重载变体都保留这个价」 |
| 上架 | 1732-1735 | 上架初始价同样用 `v.price + 初始±`，即锁定值 |

**边界**：解锁 = 把初始价输入框清空（1565）；之后重新加载会回到数据源价。锁定值按 ASIN 存，**不同站点/不同变体互不影响**；`SET.initPriceByAsin` 会一直留在 `zyp_v3_settings` 里，需要清理时直接改/删该键。

## 13. 操作要点 / 坑

1. **改完扩展必须**：`edge://extensions` 重新加载 → **F5 刷新商品页**；否则面板还是旧脚本（表现为 `Extension context invalidated`，56-71 会自动刷）。
2. **面板一开始是 🍟 圆球**，不是展开态；找不到面板先看右上角。
3. **切站点下拉会改浏览器邮编/货币并跳页**（1472-1487），不是只改面板显示。
4. **进站自动切站点**（312-336）可能"页面自己刷新一次"，这是预期行为（每个组合只做一次）。
5. **上架前提**：至少选 1 个变体 + 1 个店铺 + ifast 有跟卖方案，否则底部只提示不提交（1725-1730）；确认弹窗会列出每个 ASIN 的两个价（1757）。
6. **上架站点来自选中店铺的 `abbr`**（1753），不是设置里的「默认上架站点」；多店铺勾选 = 每个站点各发一次 `/api/ifast/add`。
7. **勾「提交亚马逊」= 上架后立即提交**（`autoUpload`，1761）；只想写 ifast 就别勾。
8. **改重量会触发运费重算**（商品级 1460 / 行级 1664-1675），观察运费列从 `…` 变成 `¥xx`。
9. **初始价锁定/手填承受价/± 会持久化**到 `zyp_v3_settings`；调试时想恢复公式价，把承受价清空、把初始价输入框清空（解锁）。
10. 面板数据全部依赖 ERP：ERP 未启动时 ① 显示「✗ 连不上…」、② 无变体，底部状态是最好用的判断入口（303-310）。
