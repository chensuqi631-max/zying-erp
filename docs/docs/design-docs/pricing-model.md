# 算价口径（Pricing Model）

> 面板、详情页、上架提交三处必须同一口径。改算价先读这里。

---

## 1. 承受价（能卖的最低/最高价）

```
承受价 = (采购¥ + 运费¥) × (1 + 利润率) ÷ K ÷ 汇率 + ±
```

- **K**：到手比例。UK 0.68 / DE 0.68 / AU 0.85，其它站点默认 0.68
  - 设置里「税率%」一栏实际存 K（填 `0.68` = 到手比例；填 `20` 会按 `1-20%` 兼容）
  - 代码：`kOf(pct)` —— `x>1` 时按 `1 - x/100`，并夹在 `[0.05, 1]`
- **德国默认 ± = −3**（沿用原面板的站点默认）
- **手填承受价优先**：填了就不再被公式覆盖（按 ASIN 持久化 `SET.manualBearByAsin`）
- 逐行覆盖：`v.cost/margin/tax/fx/adj` 任一非空 → 该变体单独算

示例（与定价表一致）：`(34 × 1.3) ÷ 0.68 ÷ 7.8 − 3 = 5.33 EUR`

### 代码位置

| 逻辑 | 位置 |
|---|---|
| 商品级基础承受价 | `zy-panel.js: bearBase()`（约 L280） |
| 逐行承受价（含手填） | `zy-panel.js: bearRow(v)` / `rowCalc(v)` |
| 上架时取值 | `zy-panel.js: uploadBearPrice(v)` |
| ERP 端算价 | `POST /api/profit/calc`（`server.js`） |

---

## 2. 初始价

```
初始价(显示) = 变体基准价(price) + 初始±(ipAdj 或商品级 initAdj)
```

- 用户在面板里改「初始价」→ 反推 `v.price = 输入值 − 初始±`
- **2026-11-22 起锁定**：改过的值写入 `SET.initPriceByAsin[ASIN]`，切网页/重载变体后回填；清空输入框解除锁定
- 上架提交的 `initPrice` = `v.price + ipAdj`（与面板显示一致）

---

## 3. 净利估算（商品详情页）

`server.js` 的 `/api/profit/calc` 逐项返回：售价、佣金（类目费率）、FBA/FBM 运费、头程、关税、仓储、其它、净利、净利率。

界面还会算：
- `referralFee = price × 类目佣金率`
- 粗略净利（列表卡片）：`price − referralFee − 3.2 − price × 0.3`（仅参考，详情页算才准）

---

## 4. 汇率与税率

| 数据 | 来源 | 备注 |
|---|---|---|
| 汇率 | `rates.json`（可刷新）+ 面板可手填 | 面板勾选「用 ERP 实时汇率」时同步到变体汇率框 |
| 税率/K | 设置 `taxBySite`（默认 UK/DE/ES/IT/FR 0.68、AU 0.85） | 可锁定（`taxLock`），锁定时输入框只读 |
| 佣金率 | `referralRateFor(cat1)` | 按一级类目 |

---

## 5. 冗余与校验

- 面板上架前会弹确认，显示「初始价 / 承受价」，必须与表格一致（`uploadInitPrice/uploadBearPrice`）。
- 差额列：`现价 − 原价`（承受价 vs 公式基准），> 0 绿、< 0 红、≈0 灰。
- **禁止**在提交时才临时重算一套不同的公式（历史事故：面板显示的价 ≠ 提交的价）。
